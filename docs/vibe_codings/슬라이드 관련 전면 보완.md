 ## 슬라이드 정보 관리 방식 관련
- AI 에 의한 생성 및 수정은 HTML 형식 구현 : 각 구성은 수정 가능한 객체(블록)화
- 저장 시 HTML을 JSON 형식 맞추어 모두 elements화 : 복구 시 이슈 없게 전환
- '저장 불러오기' 시 DB JSON 정보를 HTML 맞게 전환 
- 상호 변환에 필요한 모든 방식과 elements 정보 고려 알맞게 적용
### HTML로 구성 관련
- 각 텍스트, 이미지, 벡터는 객체로 수정 가능
#### 객체(블록) 수정 관련 
- 공통 : z-index(객체 우상 아이콘 표시) + position(드래그&드롭) + AI 재생성 변경 가능
- 텍스트 : 글자 수정, 색 수정, 너비 수정
- 이미지 : AI 통한 재생성
- 백터 이미지(차트 등) : Modal 통한 수정
### 각 페이지별 Thinking 관련
