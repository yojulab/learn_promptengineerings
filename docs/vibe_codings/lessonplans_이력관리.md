## instructors collection 
### 컬럼 추가
- 국적 : 영어(Korea, Japan etc), PDF 분석 시 추측해 입력
- 관리기관 : 기관 등록 시 기관_id, 입력자 소속 있을 때 입력됨,.

## 경력 입력  관련
- 버튼으로 변환 : 저장 버튼 왼쪽 위치
- 버튼 클릭 시 우측 메뉴에 경력 입력 화면 표시 진행
- 우측 화면 : 파일 or 텍스트 입력 표시 알맞게 화면 구성

## PDF AI 분석 관련
- instructors collection 구조 맞게 최대한 맞추기 구성
- 분석 시 화면 변경 못함
- 분석 되는 과정을 사용자에게 알맞게 메세지로 알림 표시

## main 화면 구성 관련
- 좌측, 중앙, 우측으로 분할

### 좌측 관련
- 좌측 메뉴 접힘 기능 부여 
- 우측 열리면 자동 접힘

### 중앙 관련
- profile 중 인적 정보 표시
- 나머지 묶음은 그룹 버튼으로 표시 : 클릭 시 우측에 표시(변경 가능)
- 저장 버튼은 수정 시 활성화

### 우측 관련
- 열리면 좌측 자동 접힘 : 좌측 열리면 우측 접힘
