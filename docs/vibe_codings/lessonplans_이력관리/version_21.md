[요구 사항]
## main 화면 구성 관련
- 좌측, 중앙, 우측(캔버스)으로 분할
### 좌측 관련
- 현재 메뉴 그대로 유지
- 좌측 열리면 우측 자동 접힘 : 접힘 기능 여부
### 중앙 관련
- 저장 버튼은 평소 비활성화, 항목 중 하나라도 수정 시 활성화 : 중앙이나 우측 영역 어느 것이든 해당.
#### 경력 입력 관련
- ‘저장’버튼 좌측 ‘일괄 입력’ 버튼 두기
- ‘일괄 입력’ 버튼 클릭 시 캔버스 영역에 현재 방식 알맞게 화면 표시
#### 중앙 영역 항목
- sites, education, 국적, certifications, status(pending, working 스위치, capabilityVector
- 나머지 항목은 ‘업무 경력’과 ‘강의 경력’에 업무별 버튼들로 추가 : 클릭 시 캔버스에 해당 사항 표시
### 우측 관련
- 우측 열리면 좌측 자동 접힘
- 중앙 업무별 버튼 클릭 시 해당 사항 표시
#### 우측 영역 항목
- 기존 ‘업무 경력’과 ‘강의 경력’ 리스트(항목들) 방식 그대로 사용 : 다른 업무 구성 시 참조
- 표시 대상 : workExperience, teachingExperience, skills, project 등
