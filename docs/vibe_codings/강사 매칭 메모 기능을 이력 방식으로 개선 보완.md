# 강사 매칭 메모 기능을 이력 방식으로 개선 보완 : MatchingRequestDetail.tsx
+ 세심히 분석해서 프로젝트에 알맞게 계획 세우고 적용
+ 받은 메모 상태 표시 방식 그대로 유지 : 뱃지 빨간색 표시 등
+ 필요시 다른 관련된 부분도 알맞게 적용

## 강사 매칭 메모 교환
+ 별도 collection 두어 관리하기
+ 메모 종류 : 나만 보는 메모(기본), 공유 메모
+ ‘메모’  오른쪽에 메모 종류 선택 토글 스위치 위치 : 선택 따라 메모 입력창 바탕색 변경, 버튼색과 맞추기
+ 히스토리 아이콘 버튼 : 토글 스위치 오른쪽 끝에 위치
### 히스토리 관련
- 클릭 시 오른쪽 사이드바에 주고 받은 메모들 날짜 최근부터 출력 : 첨부 이미지 참조, 풍선말에 메모 종류 따라 바탕색 다른게 표시
- 구성은 채팅창 구조 : 첨부 이미지 참조, 입력창과 보내기 버튼은 불필요
- 내가 보낸 메모는 언제든 삭제 가능
- View 모드 버튼 하나 두어 누른 때 마다 전체 메모(기본), 나만 보는 메모, 공유 메모 히스토리 변환
