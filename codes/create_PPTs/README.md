# 자동 파워포인트 슬라이드 생성기

이 프로젝트는 Python을 사용하여 파워포인트 프레젠테이션을 자동으로 생성하는 도구입니다.

## 필요 사항

1. Python 3.7 이상
2. 필수 라이브러리:
   - python-pptx: 파워포인트 파일 생성 및 편집
   - Pillow: 이미지 처리
   - pandas: 데이터 처리 (필요한 경우)

## 설치 방법

```bash
pip install python-pptx Pillow pandas
```

## 주요 기능

1. 슬라이드 템플릿 생성
   - 제목 슬라이드
   - 내용 슬라이드
   - 이미지 슬라이드
   - 차트 슬라이드

2. 콘텐츠 자동화
   - 텍스트 내용 자동 배치
   - 이미지 자동 삽입 및 크기 조정
   - 차트 데이터 자동 생성

3. 스타일링
   - 폰트 설정
   - 색상 테마 적용
   - 레이아웃 자동 조정

## 사용 단계

1. 데이터 준비
   - 슬라이드에 들어갈 콘텐츠 준비
   - 이미지 파일 준비
   - 데이터 파일 준비 (차트용)

2. 템플릿 설정
   - 슬라이드 마스터 설정
   - 기본 레이아웃 정의
   - 색상 테마 설정

3. 콘텐츠 생성
   - 슬라이드별 내용 작성
   - 이미지 삽입
   - 차트 생성

4. 마무리
   - 전체 디자인 검토
   - 파일 저장

## 프로젝트 구조

```
create_PPTs/
├── src/
│   ├── templates/      # 슬라이드 템플릿
│   ├── utils/         # 유틸리티 함수
│   └── main.py        # 메인 실행 파일
├── assets/           # 이미지, 폰트 등 리소스
├── data/            # 입력 데이터
└── output/          # 생성된 PPT 파일
```
